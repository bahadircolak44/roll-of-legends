# AGENTS.md

Instructions for AI coding agents working on **Roll of Legends** — a 3D mobile board/dice game in Unity 6.3 LTS (URP), Android first.

## Required workflow

1. **Before starting any work, read [`docs/DEV_LOG.md`](docs/DEV_LOG.md).** It holds the current state, known issues, next steps and context from previous sessions.
2. **Before finishing a session, update `docs/DEV_LOG.md`:** what changed, current state, known issues, next steps, important context, plus one short History entry. Rewrite stale lines instead of appending; keep it concise and scannable.
3. Follow [`CONTRIBUTING.md`](CONTRIBUTING.md): work on a branch (`feature/…`, `fix/…`, `chore/…`), use Conventional Commits, open a PR into `main`. `main` is protected (PR only, squash merge) — never push to it directly.

## Working with the user

- The user is a **Unity beginner**. Keep code simple and readable, avoid heavy architecture, and explain any manual Unity Editor steps click by click.
- **Assets:** 3D models come from free CC0 packs (KayKit, Quaternius) in `Assets/_Project/Art/Models` — see `CREDITS.md`. Never download anything without the user's approval (say file, source, size and license first); the repo is public, so only clearly free licenses. 2D art (cards, UI panels) is drawn in code with `Painter` (see `CardArt`).

## Batch mode (no Editor GUI)

Batch mode fails while the project is open in the Unity Editor — ask the user to close it first.

```bash
UNITY=~/Unity/Hub/Editor/6000.3.26f1/Editor/Unity

# Rebuild Main.unity from code (overwrites manual scene edits!)
$UNITY -batchmode -projectPath . -executeMethod RollOfLegends.EditorTools.PrototypeSceneBuilder.Build -logFile - -quit

# Run all tests; exit code 0 = all passed
$UNITY -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults /tmp/rol-tests.xml -logFile -
```

## Unity gotchas

- Commit every asset together with its `.meta` file. Move/rename assets inside Unity (or via `AssetDatabase`) so GUIDs survive.
- `Main.unity` is currently generated by `PrototypeSceneBuilder`. Prefer changing the builder and rebuilding over hand-editing scene YAML — but if the user has edited the scene in the Editor, ask before rebuilding.
- Empty folders are kept with `.gitkeep` (Unity ignores dot-files). Delete the `.gitkeep` once the folder has real content.
- Binary files are tracked by Git LFS via `.gitattributes`; run `scripts/setup-git.sh` once per clone.
